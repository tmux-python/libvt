# Compatibility

## Python

- **Minimum**: Python 3.12
- **Tested**: Python 3.12, 3.13, 3.14, 3.15
- **Maximum**: Python < 4.0
- **Runtimes**: CPython and PyPy (`py3-none-any.whl`, zero C extensions)

## Platforms

| Platform | Status |
|----------|--------|
| Linux | Supported |
| macOS | Supported |
| WSL / WSL2 | Supported |
| Windows | Supported (sans-I/O core and `asyncio` stream adapter) |
